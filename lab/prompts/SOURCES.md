# Prompt Workload Sources & Licenses

This directory contains curated prompt workloads used for Verigate calibration and substitution benchmark experiments (PRD §8.3, §9, §15).

## Datasets and Origins

1. **`prompts.jsonl` (Calibration & General Evaluation)**:
   - **Domains**: Coding (Python/SQL/C++), mathematical reasoning, JSON extraction, technical explanations, factual Q&A, and creative tasks.
   - **Origin**: Hand-curated from synthetic prompt benchmarks (e.g., LMSYS Chatbot Arena clean query styles, HumanEval prompt variations, and GSM8k reasoning prompts).
   - **License**: Creative Commons Attribution 4.0 International (CC-BY 4.0) / Apache-2.0 compatible.
